## GamePreloader V1.0

> 
> UE5/Unity/ForzaTech 游戏预处理加速工具，用于降低磁盘 IO 卡顿、着色器加载卡顿，面向无独立显卡设备做缓存策略适配。

### 仓库包含

- 全部源代码文件
- GamePreloader_V1.0_Release.zip`：预编译发布包，包含主程序、依赖 DLL 以及`park`引擎解析库文件夹

### 核心功能

1. **游戏进程检测**：只有监测到目标游戏进程运行后，才会启动预处理逻辑。
2. **缓存强制下限**：缓存文件创建时最小不低于 5GB；无独显设备自动提升缓存上限，帧率不达标会自动扩容。
3. **UE5 深度解析**：支持传统 Pak 与 IoStore（`.utoc`/`.ucas`）格式，兼容《黑神话：悟空》。
4. **通用资源预读**：兼容 Unity、ForzaTech 引擎游戏（《午夜轮班》、《极限竞速：地平线》系列），只读模式预加载大资源文件。
5. **系统级优化**：游戏进程提升调度优先级、切换高性能电源计划；程序退出自动清理缓存文件。
6. **界面特性**：关闭进度条动态动画，悬浮窗展示缓存大小、命中状态、预处理进度。

> 
>重要说明
> 本工具仅优化磁盘 IO、资源预热、系统调度层面卡顿，**不能突破 GPU 硬件算力上限**。核显设备运行大型 3A，建议配合游戏内 FSR/XeSS 超分辨率 + 调低画质获得更好体验。
> 程序全部为只读操作，不注入、不修改游戏本体文件，规避反作弊风险。

### 使用说明

1. 解压`GamePreloader_V1.0_Release.zip`。
2. 以管理员身份运行主程序，启动目标游戏；工具识别游戏进程后自动执行预处理。
3. 托盘右键菜单退出程序时，会自动清除本地缓存目录。

### 编译提示

本仓库仅存放 src 源码，无构建脚本。如需自行编译，请在本地工程配置 MSVC 编译环境，配置延迟加载`park/UE5PakParser.dll`解析库。
